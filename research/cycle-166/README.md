# Cycle 166 — PDF page controls and Save

Build 166 (`0.3.0-dev61`). The Mac Dev app is available for review. The signed ARM64 Mac distribution bundle was installed in `/Applications/Fomawrite.app` on 21 November and passed signature, executable identity and licence checks. The Windows VM has been opened with the ARM64 build 166 test package. ARM64 and x64 Windows test packages are available from the temporary Windows branch.

- Use the PDF menu or thumbnail context menu to rotate and delete pages, insert a PDF, or export the selected pages. Shift-click selects a range, Command-click on Mac or Ctrl-click on Windows toggles individual pages, and dragging thumbnails changes page order. Drop a PDF onto the thumbnail list to insert it.
- Page edits stay pending until Save. The window marks them as unsaved and prompts before closing or switching documents. A changed PDF on disk requires confirmation before replacement. The signed-PDF prompt asks before the first page edit, and the PDF menu opens the previous copies folder after a save.
- A successful PDF save clears page Undo and Redo. If Save rewrites page references or coordinates in the notes, Source and Live start fresh histories. Notes history survives a save that leaves references unchanged. A failed PDF write preserves both histories.
