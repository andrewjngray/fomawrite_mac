# Cycle 103 — review the actual reference workspace

Open the stable **Fomawrite Dev.app**, build **103**. Its first upgraded launch adopts the warm Manuscript source view, both navigation columns and document cards. Existing Markdown and selected export templates stay intact; later view changes persist.

1. Compare the blue tabbed folder icons, UI weight, continuous column rules and grouped circular tools with the approved concept.
2. Open a document. Check the title/date/excerpt cards and the warm source area. Try Editorial and Book from the appearance menu, then **Reference writing layout** to return.
3. Drag both dividers; collapse and reopen each navigation pane. Try a narrow window, then enlarge it again.
4. Click **Source · Manuscript** for writing modes, and the right footer appearance control for font options. Preview’s separate template selector still changes output styling.
5. Type a short change, switch appearances, Undo, and confirm only your edit is undone. Quit and reopen to confirm your chosen layout stays.

Please identify any remaining visible mismatch rather than approving from a mockup. The cycle screenshots come from the running native Qt UI with disposable sample files, not generated design images.
