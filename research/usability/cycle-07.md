# Cycle 7: compare the writing workspace

Open `examples/Preview-check.md` in both apps at similar window sizes.

1. In Omawrite choose Aa → Reset text size and turn Paragraph focus off for a fair comparison.
2. Compare text scale, gray editor background, pane widths and the shared title/toolbar area.
3. Use the library icon, the preview triangle and the bottom Split/Full controls.
4. Try Find, then Bold/Italic/Link; Save and Open are also available under More and the native File menu.
5. Check the file excerpts and persistent status at the bottom.

Tell us the three most distracting differences. Known gaps are preview template details (tables, code, quotes and heading separators), fuller formatting controls, and synchronized scrolling.
