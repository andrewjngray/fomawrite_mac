# Cycle 172 — Preview links

- [ ] Open a Markdown page with local file links in PDF Preview and right-click a link. Open it with the default app, use Open With to pick an app, or reveal it in Finder.
- [ ] Copy a file path containing spaces. Copy a text file's contents and compare Save As for a binary file with the original.
- [ ] In Web Preview, right-click a web link and copy its address. Verify that an internal anchor still navigates within Preview.
