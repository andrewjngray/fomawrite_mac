# Cycle 167 — PDF note-taking on Mac

Use a disposable copy of a PDF and its notes in Fomawrite Dev build 167.

- [ ] In PDF view, click the Note tool and a spot on the page. Type a note and choose Done. Check that the reader stays in PDF view and the pin appears at the chosen spot.
- [ ] Click the pin and edit the note. Try Escape to cancel and reopen the pin to check that the prior text remains.
- [ ] Save and reopen the PDF. Check that the edited text is still attached to the same spot.
- [ ] Try adding and editing a note near a page edge and in a narrower window.
