# Build 100 visual editing review

Use a copy of your Markdown and choose Visual Edit.

1. Edit a simple table cell and press Undo. Confirm pipe spacing and alignment markers remain unchanged in Source.
2. Select the description of a standalone local image, open Inspect image, then edit that description and Undo.
3. At the end of a list or checked task press Return; type an item, then press Return twice to exit. Check Source and Undo.
4. Edit an emoji or an accented word; switch Source/Visual/Full/Split and confirm the same text remains.
5. In a narrow pane, attempt a protected code-block edit. Confirm the explanation and Edit in Source button remain readable.
6. Write near the end of a long document and check that the caret remains visible.

Report table readability, spacing, image placement and any edits that unexpectedly require Source. These are the priorities for the next visual-editing increment.
