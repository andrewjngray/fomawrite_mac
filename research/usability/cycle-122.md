# Cycle 122 — optional review

- Open a Markdown document in Source. Confirm `**bold**`, `*italic*`, backticks, links, headings and list markers all remain visible.
- Read long bullets, nested items, numbered lists, tasks and quotes: wrapped text should align beneath the first word. Code blocks retain literal spacing.
- Switch Source / Visual Edit and Single / Split, then return to Source. Compare the literal markers and readable Manuscript spacing.
- Type two edits, Undo, change zoom, then Redo. The text and history should remain intact. Hanging-indent widths catch up after the next edit if Redo was pending.
