# Cycle 78 usability — Dock icon lifecycle

With Fomawrite pinned in the Dock, check that its tile is light when the app is closed. Launch it: the tile should change to the selected dark concept. Open a second window and hide/show the app; the icon should remain dark while the process is running. Quit normally, approving or canceling any unsaved-change prompt as appropriate. After a completed quit, the pinned tile should return to light. If Quit is canceled, it should stay dark. Repeat with Fomawrite Dev if useful.
