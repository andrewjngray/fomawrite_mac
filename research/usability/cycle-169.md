# Cycle 169 — Mac Find and PDF note cards

Use a disposable PDF and Markdown companion in Fomawrite Dev build 169.

- [ ] In Split, focus Source and open Find. Type mixed ascenders, descenders, and diacritics into Find and Replace. Check that the text and cursor are centred in both fields.
- [ ] Hover on a note pin, then move away. Right-click the pin and verify that both copy actions give the full note, with a page link for the Markdown quote.
- [ ] Open a note card and drag its header. Try Done, close, and Delete followed by Undo.
- [ ] Create a new note, save, and reopen it. Check that the footer gives the creation time and that later edits keep it.
