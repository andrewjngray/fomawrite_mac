# Cycle 89 review

Use disposable saved Markdown files while comparing independent views.

1. Right-click the current file and choose Open in New Window. Confirm a separate window contains that file.
2. From the original window, choose Open in New Tab. Confirm the new tab belongs to that window.
3. Type a draft and try opening another view; confirm the message asks you to save first.
4. With two views open, edit both, save the first, then save the second. Confirm the second draft survives and cannot overwrite the first save without resolving the conflict or saving elsewhere.
5. Use Copy, Favorite, Get Info, Duplicate and Export on a different library file while keeping a draft open. Confirm each action targets the clicked file.
6. Try the Print submenus and cancel them, then inspect Share and Show in Finder without sending anything.

Independent views are not live synchronized. Save/Reload or Save As resolves changes between them. Close other views before renaming or trashing the shared file.
