# Cycle 125 — optional theme-folder review

Target build **0.3.0-dev21 / macOS 0.3.0 (125)**. Final regression and native verification are pending; see the [draft handoff](../cycle-125/README.md). Use a disposable Markdown sample with headings, a quote, a table and fenced code.

- Open Themes Folder. Add a theme CSS file at the folder's top level, with any font/image/resource folders beside it. Confirm the theme appears automatically, including a name containing capitals or underscores. Nested archive CSS should stay outside the chooser.
- Choose the theme from the publishing footer or View menu. Confirm one checked selection, comfortable scrolling with many entries, and matching Web/PDF styling in the workspace and Export and share.
- Edit the selected CSS, then add/remove a disposable theme file. Confirm the preview and list update without choosing Custom Settings or pressing Reload Themes. Restore the disposable files afterward.
- Import a theme that uses local resources. Confirm it becomes available in the same folder. A missing optional font should give an advisory and use fallback typography; a forbidden remote resource should give useful failure feedback while retaining the previous choice.
- Open Basic Settings / Edit Basic Settings and Custom Settings. Confirm these controls are distinct from CSS themes. Switch Source/Visual Edit and Single/Split, make a disposable edit, and Undo it; document text and history should remain intact.

Record any stale list/preview, duplicate checkmark, clipped chooser, confusing settings action, unexpected font fallback or changed pagination. Keep private writing and theme contents out of screenshots and public records. Physical printer and VoiceOver checks remain separate optional acceptance work.
