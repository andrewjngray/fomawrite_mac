# Cycle 44 usability

- Right-click a Markdown or text file without opening it: Get Info, Copy, Export and Print should target it.
- Duplicate a note with unsaved edits: the copy should include those edits while the original stays dirty.
- Open another note in a new tab/window; check that the library context stays useful.
- Right-click a folder: create a child file and folder, favorite it, duplicate or rename it after closing contained documents.
- Move only a disposable copy to Trash; confirm the original is untouched.
- Try Sort By and View Options, and report confusing order, spacing or keyboard behaviour.
- Share uses the saved disk file; save edits first if you want them included.
