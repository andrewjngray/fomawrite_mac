# Cycle 104 — folder heading and quick text size

Open **Fomawrite Dev.app**, build **104**.

1. Check the blue folder glyph and quiet button outline beside the current library folder name. Click it to choose a folder with the familiar native picker, or Cancel to keep the current folder.
2. Check the visibly bold **B**, italic **I**, link and paragraph group. Select a short Source phrase, apply Bold, then Undo.
3. Use the **− / +** group between formatting and **Aa**. Try the first minus click and successive plus clicks in Source, Preview and Visual Edit. Output template and export font size should stay unchanged.
4. Narrow the window, collapse/reopen the navigation columns and try text size again. The buttons should remain usable without overlapping.

The native screenshots use disposable sample text. Physical VoiceOver and display-scale review remain open; the cycle does not expand the supported Visual Edit grammar.
