# Cycle 123 — optional review

Build target: **0.3.0-dev19 / macOS 0.3.0 (123)**. Verification and refreshed app identities are **PENDING**; consult the [handoff](../cycle-123/README.md) before comparing local copies.

- In Source, choose **Aa → Manuscript**. Read a long `### Heading`: its markers should hang to the left, while its first word and wrapped lines align with the body paragraph below. Read lists and quotes beside that same column.
- Add a fenced JavaScript block with an empty line. Its subtle background should remain continuous through the blank line and both fences. Inline backticks should colour only their short inline span.
- Choose **Aa → Code**, or **View → Writing Appearance → Code**. Compare Menlo, tighter spacing, line numbers and indentation guides. Try a long line and scroll horizontally. Switch Single/Split and light/dark themes.
- Select two code lines, press Tab, then Shift-Tab. Undo each operation. Place the caret after an opening brace and press Return: the new line should inherit indentation and add one level. Undo should remove that newline and indentation together.
- With prose smart punctuation enabled, type a straight quote and two hyphens in Code and paste a plain URL. They should remain literal. Compare known fenced languages or a supported code file with an unknown fence language.
- Cycle through Code, Book, Editorial and Manuscript, then save a disposable document. The Markdown text should stay exact. Type an edit, Undo, change appearance, then Redo; text history should survive. Presentation widths may catch up after the next safe edit when Redo was pending.

Note any clipped heading marker, broken empty-line background, unexpected indentation or lost reading position, together with the appearance and Single/Split choice.
