# Cycle130 optional menu review

Confirm **0.3.0-dev26 (130)** in About Fomawrite.

1. Open **Output Style** below the publishing pane. Hover **Custom Themes ›**, then select a theme; check that output and the sole checkmark agree.
2. Choose Modern (Sans) from the parent menu; verify it changes output and leaves the source unchanged.
3. Compare the View → Output Style menu with the footer menu.
4. Read [the menu guide](../../docs/output-style-menu.md), especially Custom Themes versus Custom Settings, and flag labels or actions that still feel unclear.
