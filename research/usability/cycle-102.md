# Cycle 102 optional review

Use Fomawrite Dev `0.3.0-dev3` / build `102` with a disposable document.

1. Hide Organizer, then Library using their header controls. Reopen each from the small buttons that remain at the left of the writing header; try both orders.
2. Shrink the window. If a pane cannot dock, its button should open temporary navigation; Escape returns to writing.
3. Open View. Toggle Library and Toggle Organizer should be first, with stable labels and accurate checks. Template should have a separator above and below.
4. In Preview, click the template name in the bottom bar, choose Palatino, then change back through View → Template. The name, checkmarks and document preview should agree.
5. Repeat in a narrow preview pane and Dark theme. Return to Source and confirm your text and Undo history remain intact.
