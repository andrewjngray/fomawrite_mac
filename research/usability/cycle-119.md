# Cycle 119 review

1. Open a Markdown document with headings, a table and a local image; select Split.
2. Switch Source / Visual Edit beneath the left pane; confirm the right stays read-only.
3. Switch Web / PDF beneath the right pane; check PDF pages against an export and Web against HTML.
4. Resize the divider and zoom each pane independently; check reading positions and compact menu labels.
5. Type and scroll: document bars hide without moving the page. Hover top and bottom separately to recover controls.
6. Use F6 and open a menu; controls remain accessible. Turn off View → Auto-Hide Document Bars to keep them visible.
7. Change Single / Split repeatedly, then Undo an edit and save. Report any control ownership, position or source-preservation problem.
