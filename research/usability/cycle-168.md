# Cycle 168 — PDF toolbar on Mac

Use a disposable PDF in Fomawrite Dev build 168.

- [ ] Rotate the current page, then select two thumbnails and rotate both. Undo the rotation before saving.
- [ ] Arm the pen and the Note tool in turn. Verify the active outline and instruction, and press Escape to return to reading. Place and edit a note using the popover.
- [ ] Choose Fit Page from the arrow beside Fit Width. Resize the window and reopen the PDF. Find Fit Page and Rotate in the overflow in a narrow Split pane.
