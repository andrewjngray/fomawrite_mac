# Cycle 32 — optional five-minute exercise

Use disposable Markdown files.

- Open two documents in separate windows and merge them with Window → Merge All Windows.
- Put the cursor halfway through the second document; Quit and reopen Omawrite Dev.
- Confirm both tabs, their order and cursor return.
- Open an already-open file again; confirm its existing tab is selected.
- Edit a sample, Quit, choose Cancel and confirm your text remains.
- Report any unexpected focus, missing tab or changed cursor. Fullscreen/minimized and display changes remain follow-up checks.
