# Cycle 106 — footer review

Use build 106 (`0.3.0-dev7`) from the stable Fomawrite Dev app.

1. Open a disposable document, enter an unsaved sentence, and try Source → Split → Preview → Visual Edit → Source from the footer controls. Repeat an option to check that the menu remains responsive.
2. Change Manuscript / Editorial / Book at the bottom, then try larger/smaller/reset text. The document and export template should stay unchanged. Undo should still remove only the sentence you typed.
3. Click the Preview template pill and select Palatino, then another style. Try Split/Full and Visual Edit. All controls should remain reachable when Preview is narrow.
4. Resize to a short/narrow window, collapse/reopen navigation and try dark mode. Footer rules should line up, menus should open above their buttons, and no button should cover another.
5. Enter and clear text in Filter files. Compare the bottom controls with the top toolbar for font, tone, shape and hover clarity.

Record any confusing label or failed click, including the current view and window width. Physical VoiceOver and display-scale checks remain open.
