# Cycle 54: explicit completions and opt-in smart punctuation

Phase 54a adds the captured View → Show Completions action as an explicit local request. Direct isolated iA samples then established bounded Smart Quotes and Smart Dashes behavior. Phase 54b implements the observed quote subset. Phase 54c independently implements only the observed `--` to em-dash rule; it does not infer other substitution or correction behavior.

View → Show Completions uses Unicode words in the current document. It excludes code spans/blocks, indented code and URL/link destinations. Nothing is inserted until a suggestion is accepted; acceptance rechecks the caret and unchanged prefix, then makes a single atomic replacement for Undo. IME preedit is excluded. Work is bounded to the first 50,000 UTF-16 units and 256 matching occurrences, with at most 12 choices; later words may be omitted.

`./bin/build` and the full native-access `./bin/test` suite pass with **89 tests, zero failures and zero skips**. Focused tests cover the candidate rules, stale-caret refusal, Undo and a long-document time bound. The refreshed Dev app displayed two suggestions for `lan`; Return accepted one and Command-Z restored the prefix in a disposable temporary file. [Native log](native-menu.txt). Popup visuals, arrow traversal, Escape, dark/narrow appearance, IME and accessibility remain unverified because screenshot capture was unavailable. Use only [the synthetic sample](sample/Completion.md) for further QA.

Smart Quotes is off by default and persists as a workspace preference under Edit → Substitutions. It handles only a directly typed `"`; paste and selection replacement never enter the substitution path, and active IME composition is refused. It inserts `“` after whitespace/open punctuation and `”` after prose/closing punctuation. The literal keystroke and substitution are separate undo records: the first Undo restores `"`, and the second removes it. Fenced, indented and inline code, bare URLs, Markdown link destinations and incomplete raw tags are excluded. Existing Markdown is never scanned or rewritten, and the saved file remains ordinary UTF-8.

Smart Dashes is separately off by default and persisted. When enabled, a directly typed second `-` changes a spaced prose pair such as `one -- two` to an em dash. Its first Undo restores the pair and its second Undo removes only the second hyphen. It refuses active selection or IME composition, paste and modified shortcut input, and uses the same fenced/indented/inline code, bare URL, link destination and incomplete raw-tag exclusions. Line-leading rules/front matter, adjacent third hyphens and unspaced forms remain literal. Existing pairs are untouched. This is the only observed dash rule implemented.
