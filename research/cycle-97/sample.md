# A quieter place to write

Fomawrite keeps plain **Markdown** editable while giving the page more room and a softer tone.

## A familiar workspace

The organizer, file list and writing canvas each have their own controls. Blue folders stand out against a quiet sidebar; grouped actions keep the writing tools together.

- Choose Editorial for everyday writing.
- Try Manuscript for a typewriter feel.
- Try Book for a serif writing view.

## Make room

Collapse a column with its header button, then restore it from Workspace. Narrow the window and grow it again: the requested columns return when there is enough room.

Visual Edit supports a bounded set of text edits. Source remains available for the complete Markdown document.
