# Cycle 55: Focus grouping and live style checks (partial)

The captured iA Focus menu places Sentence, Paragraph and Typewriter under Enable Focus Mode. Omawrite now uses that hierarchy while preserving sentence/paragraph exclusivity and independent typewriter scrolling. Writing Review remains an Omawrite-specific action after the captured groups.

Phase 55b adds Focus → Enable Style Check → Custom. It is opt-in, persisted and uses the comma-separated terms entered in Writing Review. Text and term changes refresh after about 200 ms; disabling clears the overlay immediately. Matching is offset-preserving, Unicode-aware and bounded to the first 50,000 UTF-16 units, 32 unique terms of at most 64 units and 1,000 ordered non-overlapping results. Fenced, indented and inline code and URL syntax are excluded. Review formatting composes with Markdown and focus formatting, and search highlighting has priority. The source, caret and Undo history are not changed.

Phase 55c adds an independent persisted Fillers toggle. Its starter terms are `very`, `really`, `quite` and `just`, using case-insensitive Unicode whole-word matching. Fillers and Custom merge globally under the same first-50,000-unit and 1,000-match limits; Custom wins an exact overlap. Turning either category off removes only its matches immediately. Both exclude fenced, indented and inline code, URL destinations and raw tags.

`./bin/build` and the full native-access `./bin/test` suite pass with **96 tests, zero failures and zero skips**. The stable `dist/Omawrite Dev.app` was refreshed with combined Cycle 55c/56a source. Native QA found both Fillers and Custom. Toggling Fillers on the synthetic `research/cycle-47/sample/Templates.md` fixture left source and saved status unchanged. Earlier Custom QA used [`sample/Custom-review.md`](sample/Custom-review.md). Screenshot capture was unavailable, so pixel styling remains unverified. See [`native-fillers.txt`](native-fillers.txt), [`native-custom.txt`](native-custom.txt) and the [optional usability exercise](../usability/cycle-55.md).

Clichés, Redundancies and Show Syntax are not implemented. Checked-state visuals, overlay color, dimming/scroll feel, keyboard traversal, narrow/dark/fullscreen and VoiceOver remain open.
