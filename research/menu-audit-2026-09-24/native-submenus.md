# iA Writer native menu follow-up — 24 September 2026

Read-only accessibility inspection of the installed iA Writer with an existing document open. No document or iA setting was changed. Personal recent-file names, location names, hashtags, display names and document text are intentionally omitted. Menu enabled states vary with selection, authorship setup and macOS version.

## File

- Revert To → Browse All Versions…
- Share → AirDrop, Mail, Messages, Notes, Freeform, Journal, Reminders, Dropbox Transfer, More… (system share extensions vary)
- Print → Print…, Print Plain Text…
- Export… is a direct item; its dialog was not opened.

## Edit

- Paste As, Paste Edits From and Mark As each showed only Set Up Authorship… before an author identity was configured. Their post-setup items remain unknown.
- Find → Find…, Find Next, Find Previous, Use Selection for Find, Find and Replace…, Replace, Replace All, Filter Library…
- Spelling and Grammar → Show Spelling and Grammar, Check Document Now, Check Spelling While Typing, Check Grammar With Spelling, Correct Spelling Automatically.
- Substitutions → Show Substitutions, Smart Copy/Paste, Smart Quotes, Smart Dashes, Text Replacement.
- Transformations → Make Upper Case, Make Lower Case, Capitalize, Make Title Case.
- Speech → Start Speaking, Stop Speaking.
- AutoFill → Contact…, Passwords…, Credit Card…; Start Dictation and Emoji & Symbols followed as platform items.

## Authors and View

- Authors showed Set Up Authorship… only. The setup sheet has required Name, optional Identifier (example: email or website), Save disabled until a name is entered, and Cancel. The sheet says the name may also be used by templates for preview/export/print. We canceled without entering data. Post-setup Authors menu remains unknown.
- View → Preview → PDF contains Fit Page and Fit Width. View → Template lists Modern (Sans), Classic (Serif), Manuscript (Mono), Manuscript (Duo), Manuscript (Quattro), GitHub, Helvetica, MLA Style and Palatino. View → Show Completions is a direct action; its suggestion behavior was not exercised.

## Application, Window and Help

- Application → About iA Writer, Check for Updates…, Settings…, Services, Hide, Hide Others, Show All, Quit iA Writer, Quit and Close All Windows.
- Window → Minimize/Minimize All, Zoom/Zoom All, Fill, Center, Move & Resize, Full Screen Tile, move to an external display when available, Bring All to Front, Arrange in Front, tab/window-set actions, and the current window list. Move & Resize offered halves, quarters, arrangement combinations and return to previous size, with some entries disabled in this state. Exact OS-owned availability is dynamic.
- Help → search, iA Writer Help, What’s New in iA Writer, Visit Online Support.

This capture resolves menu labels and hierarchy, not behavior parity. Post-authorship setup entries and exact substitutions, correction and completion behavior still require safe sample-based observation. System services and share targets should remain delegated to AppKit where available.
