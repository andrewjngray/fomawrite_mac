Fomawrite for Windows: platform notices

Read THIRD-PARTY-NOTICES.txt first; it covers Fomawrite, Qt, Qt WebEngine
(Chromium), Qt PDF (PDFium), the Live editor's JavaScript packages, Harper,
MD4C and the fonts. This file adds what is specific to the Windows build.

Qt 6.11.3 libraries come unmodified from the official open source SDK
(https://download.qt.io/archive/qt/6.11/6.11.3/), dynamically linked as the
Qt6*.dll files beside Fomawrite.exe, under the LGPL v3. They may be replaced
with ABI-compatible builds of the same Qt version.

Qt WebEngine does not serve Chromium's chrome://credits page. Qt lists the
Chromium third-party components and their licences at
https://doc.qt.io/qt-6/qtwebengine-licensing.html. When the Qt SDK supplies a
generated credits file, it is included as QtWebEngine-Chromium-credits.html.

dxcompiler.dll and dxil.dll are Microsoft's DirectX Shader Compiler, shipped
with Qt for its Direct3D 12 backend, under Microsoft's redistribution terms.
The Visual C++ runtime files are Microsoft redistributable components deployed
app-locally from the selected compatible v14 runtime, under Microsoft's
redistribution terms.

qpdf (page editing) comes from vcpkg (commit pinned in windows/vcpkg-baseline.txt),
built dynamically for the package's architecture, as qpdf*.dll beside
Fomawrite.exe, with the DLLs it loads that Windows does not provide:
  qpdf, Apache License 2.0 (licenses/qpdf-Apache-2.0.txt).
  zlib1.dll, zlib licence (licenses/zlib-copyright.txt, vcpkg's copy).
  jpeg62.dll, libjpeg-turbo: BSD-3-Clause, IJG and zlib terms
  (licenses/libjpeg-turbo-copyright.txt, vcpkg's copy).
qpdf is built with its own cryptography, so no OpenSSL DLL is shipped. The exact
DLLs deployed are listed under vcpkgDlls in manifest.json.

The application and dependency versions, source commit, archive checksums,
executable, embedded resources and deployed file hashes are in manifest.json.

This internal artifact is unsigned. It has not been qualified as a public release.
