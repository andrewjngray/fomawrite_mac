## 0.3.0 development series (Cycles 97–)

- **142** — Source editor answers accessibility character geometry (`0.3.0-dev38`, build 142, 9 Oct): Grammarly Desktop attached to nothing in build 141 because neither Qt Quick nor Qt WebEngine reports character bounds to macOS Accessibility (upstream stubs, found by a probe test); the Source editor now supplies real bounds and point-to-offset answers through its own accessibility factory, keeping the editable-text interface. Live cannot be fixed in-app. Hand test pending. [Record](research/cycle-142/README.md)
- **141** — highlighted text readable under any theme (`0.3.0-dev37`, build 141, 9 Oct): `==highlight==` takes the theme's `--highlight-color` with a text colour chosen for contrast, in Live and in Web/PDF; both native harnesses pass against build 140. [Record](research/cycle-140/README.md)
- **140** — Live friction fixes (`0.3.0-dev36`, build 140, 9 Oct): the footer's layout capsule names Preview (Single | Split | Preview, one click each way); the app's chrome follows the Output Style's page colours when the theme defines them (View → Appearance Follows Output Style, default on; dark Typora themes darken the window); Typora base shim: themes that define their colours as `:root` custom properties (Lapis Dark: `--bg-color`, `--text-color`, `--select-text-bg-color`, ...) now paint the page in Web/PDF output and in Live (the host sends a small shim ahead of the theme CSS; explicit theme rules still win); the host can read a theme's variables (`Publisher::themeVariable`, `Backend::themeBackgroundColor`). [Record](research/cycle-140/README.md)
- **139** — first Live friction fixes (`0.3.0-dev35`, build 139, 9 Oct): View → Editing and Layout ticks re-asserted when the native submenus open (they showed stale after opening in Preview Only); the Live friction list started at [docs/live-friction.md](docs/live-friction.md).
- **138** — Live selection race and native theme-folder checks (`0.3.0-dev34`, build 138, overnight 8 Oct): Format/copy commands in Live ask the page for its current selection (`requestSelection`/`selectionReply`) instead of the debounced report, queued per document with a one-second fallback; the theme-folder acceptance fixture creates the folder the app deliberately stopped creating in Cycle 132; harness wrapper thresholds and resource list aligned. [Record](research/cycle-138/README.md)
- **137** — Live theme fidelity (overnight 8 Oct, shipped with 138): review fixes for Cycle 136 (theme face and line height win over the host's in Live, readability by measured background and WCAG contrast, exact mode keeps mapped typography, tables full measure, revealed marks ignore theme colour), `ul`/`ol` distinction, absolute sizes converted to `em` against the theme or root size, quote spacing, a gallery of every bundled Output Style in filtered Live with a contrast assertion. [Record](research/cycle-137/README.md)
- **136** — Live follows the publishing theme, lighter (`0.3.0-dev32`, build 136, 8 Oct): the Live page applies the Output Style CSS through an editing overlay that keeps typography and neutralises layout, maps the theme's element rules onto Live's lines, ignores the Source appearances in Live, fills unreadable colours from the palette; View → Live Follows Theme Exactly as the escape hatch; the left control names the Output Style in Live. [Record](research/cycle-136/README.md)
- **135** — Visual Edit retired, builds aligned (`0.3.0-dev31`, build 135, 7 Oct): `VisualEditPane.qml`, the bounded `SourceVisualMapping` and `VisualTextHighlighter` removed with their Backend API, footer option, menus, workspace flag (a saved Visual Edit choice restores as Live) and the mapper/visual test suites; native acceptance steps drive Live; new `bin/install-mac`; `dist/` and `/Applications` bundles refreshed to 135 and the stale Omawrite bundles removed. [Record](research/cycle-135/README.md)
- **134** — the Live editor (`0.3.0-dev30`, build 134, overnight 6–7 Oct): CodeMirror 6 editor page hosted in the app's WebEngineView over QWebChannel (`src/editor/`, `EditorBridge`, `LiveEditorPane.qml`); byte-exact two-way mirror with the canonical document; Live mode (inline marks, images, tasks, rules, highlighted fences, table grids, KaTeX math), Source/Code appearances with focus and typewriter; theme pass-through, scroll sync, cursor carry-over, Format/Undo/Find routed to the page, footer Live option, outline navigation into Live, image paste/drop saved beside the document (refusals shown as a notice), in-page link editor, inline math inside table cells, the Edit menu acting on the page (clipboard, copy formats, Paste As), mirror recovery from out-of-range host changes, curated fence languages (bundle 1.9 → 1.4 MB), footnotes/TOC/front matter; measured 1 MiB load ~55 ms; screenshots in the record; per-process test app data; CI click flakes root-caused and a focus-steal app bug fixed. [Record](research/cycle-134/README.md)
- **133** — structure, CI and the measured hot path (`0.3.0-dev29`, build 133): GitHub Actions CI with pinned Qt 6.11.3; docs consolidated into `STATUS.md` / `CHANGELOG.md` / `ARCHITECTURE.md` with stale docs archived; publishing extracted into `Publisher` behind `PublishingSource`; dead paths removed; `macbridge.h`; `NativeMenuBar.qml`; `PreviewPane.qml` → `VisualEditPane.qml`; R2 performance profile; mapper O(n²) fixed (100 KB line 4.1 s → 0.7 ms); R3 property/fuzz tests (no corruption found, two cursor defects pinned); 220 tests.
